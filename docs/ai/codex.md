# [codex](https://openai.com/zh-Hans-CN/codex/?utm_source=Ai138.com)

## 安装 codex

cli 工具安装：
```
npm install -g @openai/codex

codex --version
```

或 桌面应用App

## 配置文件
```
C:\Users\Administrator\.codex\config.toml

~/.codex/config.toml
```

```
codex mcp add figma --url https://mcp.figma.com/mcp
```

```
codex mcp list
```
