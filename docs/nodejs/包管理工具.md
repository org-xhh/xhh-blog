# 包管理工具

## npm

Node.js 的默认包管理器

版本锁定文件：package-lock.json
---
> npm v12 默认禁止生命周期脚本执行
```
简单来说，以后执行：

npm install

默认不会再自动运行依赖中的：

preinstall
install
postinstall
prepare

等脚本
```


## cnpm

是淘宝镜像的命令行工具，用于加速安装依赖包。

```
npm install -g cnpm --registry=https://registry.npmmirror.com
```


| cnpm version     | npm version |
| ---------------- | ---- |
| 7.1.1            | ^6.13.4  |
| 8.6.1            | ^8.12.1  |
| 9.2.0            | ^9.6.2   |

## yarn

是 Facebook 开源的包管理器。

版本锁定文件：yarn.lock

---
> yarn v4 默认禁止生命周期脚本执行

## pnpm

使用硬链接和符号链接，节省磁盘空间，安装极快。严格避免幽灵依赖（未声明的依赖不能引用）

```
npm install -g pnpm
```

版本锁定文件：pnpm-lock.yaml

---
> pnpm v10 默认禁止生命周期脚本执行

---

https://pnpm.io/zh/pnpm-cli

## npx

是 npm5.2.0 版本后内置的命令行工具，临时运行安装在项目中的包命令，而无需全局安装这些包。
