图片加载模式 ​

适用场景单纯页面展示图片，不需要 canvas 读取像素Canvas 合成、海报生成、读取图片像素、导出图片（绝大多数图片业务首选）图片资源需要身份凭据（Cookie、登录态）才能访问；内网鉴权图片，极少用于公开OSS图片

补充说明：

  1. no-cors 模式下，JS 依然可以读取图片宽高 img.width / img.height 这类元信息；安全限制仅针对像素数据提取（getImageData / toDataURL）。
  2. use-credentials 属于CORS模式，校验通过画布不会污染，但CORS配置约束更强，公开无鉴权图片场景优先使用 anonymous。
  3. 核心坑：同一个图片URL，不要混合多种加载模式，会触发Chrome opaque 缓存隔离问题。
  4. 关键区分：no-cors 模式：图片看得见，能绘制画布，只是不能导出、读像素；anonymous / use-credentials（CORS模式）：校验失败直接拦截，图片都看不见。
  5. fetch mode: 'no-cors' 重点：请求能发出去、状态200，但是响应body是不透明的，JS拿不到二进制，不能转base64，无法用来处理图片。

✅ 不受限制（no-cors 也能读）：图片元信息

const img = new Image();
img.src = "跨域无CORS图片地址";
img.onload = () => {
  console.log(img.width, img.height); // 宽高，正常读取
  console.log(img.naturalWidth, img.naturalHeight); // 原图尺寸，正常读取
};

这些信息是图片解码后浏览器暴露在 HTMLImageElement 对象上的基础属性，不需要访问像素原始数据。

❌ 受限制（no-cors 画布污染，直接报错）：像素提取操作

ctx.drawImage(img, 0, 0);
ctx.getImageData(0,0,10,10); // 读取像素 RGBA → 报错
canvas.toDataURL(); // 导出画布为base64 → 报错
canvas.toBlob(()=>{}); // 导出blob → 报错

原因：一旦跨域图片以 no-cors 模式绘制进 canvas，画布被打上 tainted（污染） 标记。浏览器禁止把画布的像素内容往外泄露，防止隐私 / 资源窃取。

缓存机制 ​

Chrome 浏览器规则：no-cors 拿到的 opaque 缓存响应，不能给后续 cors 模式的同 URL 请求复用，哪怕这个响应本身携带 CORS 头

JS读取图片信息报错，复现顺序：

  1. 页面先通过普通 img /css 背景图（no-cors）加载图片 → 生成 opaque 缓存条目
  2. JS 使用 new Image()+crossOrigin="anonymous" 请求同一个图片地址
  3. 浏览器命中旧的 opaque 缓存，拒绝复用，直接抛出 CORS 报错
  4. F12 勾选【禁用缓存】：不走缓存，重新向 OSS/BOS 发起 CORS 请求，校验通过，代码正常

解决方案 ​

  1. ✅ 方案 1：请求拼接时间戳（快速修复，适合 Canvas 一次性合成场景）

给 Canvas 使用的图片 URL 增加随机参数，强制绕过缓存：

const img = new Image();
// img.crossOrigin 必须在设置 src 之前赋值
img.crossOrigin = 'anonymous';
const imgUrl = 'https://su.bcebos.com/test/xxx.png';
img.src = `${imgUrl}${imgUrl.includes('?')?'&':'?'}_t=${Date.now()}`;
  1. ✅ 方案 2：全站统一图片加载模式（前提：页面不存在 CSS 背景图引用该图片）

页面所有<img>标签，全部增加 crossorigin="anonymous"，所有同 URL 请求全部走 cors 模式，缓存条目统一为 CORS 响应，不会冲突

限制：CSS background-image 无法设置 crossorigin，只要用到背景图，该方案失效

  1. ✅ 方案 3：同源

图片变成同源资源，完全规避 CORS + 缓存隔离问题

  1. ✅ 方案 4：后端提前转 Base64 返回（适合小图如二维码）

后端拉取远程图片，转 base64 字符串返回前端，data:image格式无网络请求，不存在跨域、缓存问题；缺点是体积增大，不适合大图。

图片预加载 ​

图片预加载是指在页面加载时提前加载图片，使其缓存在浏览器中，当用户需要查看图片时立即显示，不需要等待加载。

let image = new Image();
image.src = 'image.jpg';
<link rel="preload" href="image.jpg" as="image">

图片懒加载 ​

延迟加载图片，用户滚动到页面上特定位置时才加载图片。

<img data-src="https://xxx.jpg">

getBoundingClientRect ​

const debounceLazyLoad = debounce(imgLoadFn, 100)
window.addEventListener('scroll', debounceLazyLoad)
window.addEventListener('resize', debounceLazyLoad)
imgLoadFn() {
  let that = this
  let imgGroups = document.getElementsByTagName('img')
  let imgGroupLen = imgGroups && imgGroups.length
  // 最后一张图片还没加载出来，说明需要懒加载
  if (imgGroupLen && imgGroups[imgGroupLen - 1].getAttribute('data-src')) {
    for (let i = 0; i < imgGroups.length; i++) {
      let imgItem = imgGroups[i] || {}
      if (imgItem.getAttribute('data-src')) {
        that.loadImg(imgItem)
      }
    }
  }
},
loadImg(el) {
  // 获取窗口高度
  let docHeight = document.documentElement.clientHeight
  let boundingClientRect = el.getBoundingClientRect()
  let bottom = boundingClientRect.bottom
  let top = boundingClientRect.top
  /* 当元素进入窗口时，才加载真实图片
    bottom： 元素的下边到窗口上边的距离
    top： 元素的上边到窗口上边的距离
  */
  if (top < docHeight && bottom > 0) {
    el.src = el.dataset.src
    el.removeAttribute('data-src')
  }
  // top >= docHeight || bottom <= 0 // 不可见
}

IntersectionObserver (推荐) ​

function query(selector) {
  return Array.from(document.querySelectorAll(selector))
}

let observer = new IntersectionObserver(function(entries) {
  entries.forEach(function(entry) {
    // intersectionRatio 图片可见比例 0-1
    if (entry.isIntersecting) { // 在视口
      let img = entry.target
      if (img.dataset.src) {
        // dataset.src 就是 获取 "data-src" 属性值
        img.src = img.dataset.src
        img.removeAttribute('data-src')
        // 图片已加载， 解除观察
        observer.unobserve(img)
      } else {
        observer.unobserve(img)
      }
    }
  })
}, { threshold: [0] }) // 元素刚进入视口的一瞬间触发；
// rootMargin: '50px 0px'  提前50px触发

query('img').forEach(function(item) {
  // 观察每个图片对象
  observer.observe(item)
})

loading="lazy" ​

loading 是 <img> 和 <iframe>> 标签的新属性，在 <img> 标签上添加 loading="lazy"，浏览器就会在图片滚动到视口附近时才开始加载。

<img src="image.jpg" loading="lazy" width="350" height="220" alt="图片" />
